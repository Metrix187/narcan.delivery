# Spanish state pages: translation progress

Per-state Spanish pages live at `/es/states/<slug>/`, generated by `build.mjs`
from `data.es.js` (`window.NALOXONE_ES`).

**To translate a state:** copy an existing block in `data.es.js`, change the
abbreviation, and translate the fields. Then run `node build.mjs`. The build
creates the page, adds reciprocal hreflang on the English page, lists it on the
`/es/` landing, adds it to the sitemap, and links neighbor chips ES-to-ES when
both sides are translated.

Per-state fields (all optional; English fills any gap): `naloxone_legal_status`,
`gs_scope`, `pharmacy_mechanism`, `medicaid_notes`, `typical_cost`, `how`,
`barriers`, `community_services[]`, `mail_services[]` (arrays match the English
orgs by position; org names stay as-is). Keep the plain-voice style: no em
dashes, no shouty caps.
