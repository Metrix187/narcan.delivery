# Spanish state pages: translation progress

**All 50 states are translated.** Every state has a Spanish page at
`/es/states/<slug>/`, generated by `build.mjs` from `data.es.js`
(`window.NALOXONE_ES`).

**To update or correct a state:** edit its block in `data.es.js` and run
`node build.mjs`. The build regenerates the page, reciprocal hreflang on the
English page, the `/es/` landing directory, the sitemap, and ES-to-ES neighbor
chips.

Per-state fields (all optional; English fills any gap): `naloxone_legal_status`,
`gs_scope`, `pharmacy_mechanism`, `medicaid_notes`, `typical_cost`, `how`,
`barriers`, `community_services[]`, `mail_services[]` (arrays match the English
orgs by position; org names stay as-is). Keep the plain-voice style: no em
dashes, no shouty caps.

## Status: 50 / 50 done

All states translated. When the English source data for a state changes
materially (a new law, a program shutting down), update the matching Spanish
block so the two stay in sync.

Note: only the per-state card text is translated. The state DATA itself
(`data.js`) and the global pages (`/`, `/card/`) remain English aside from the
`/es/` landing.
